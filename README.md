# ゴーゴークイック 参加型ポイントオーバーレイ

Overwatchの参加型企画用、配信オーバーレイです。ユーザーごとにポイントを加減算し、配信画面にリーダーボードとして表示します。ビルドステップ不要の静的サイトで、状態はFirebase Realtime Databaseにリアルタイム同期されます。操作パネルはスマホなど任意のブラウザから開けます。

🔗 公開URL: https://gogomac.netlify.app

## ファイル構成

- `index.html` — トップページ（表示画面・操作パネルへのリンク）
- `display.html` — 配信画面に映す表示用ページ（OBSのブラウザソースに指定）
- `control.html` — ポイントを操作するページ（スマホ等、配信には映さない別デバイスから開く。初回のみパスコード入力が必要）
- `firebase-config.js` — Firebase接続設定（display.html/control.html共通で読み込む）

## ルール例（このリポジトリのデフォルト設定）

**＋1ポイント**
- POTGを取る／MVP画面に載る
- タンク/DPSのとき、自分の倍以上のダメージを出す
- 「行かないで」など引き留められる
- わかりにくい／グルタイミングでのデス

**－1ポイント**
- キュンとさせる（守られるなど）
- 1人で拠点を管理する
- チームを勝たせたと思われる行為
- ダイブ/ラッシュ魂を捨てる行為

**累積ボーナス／ペナルティ（±10到達で自動発動・自動リセット）**
- 合計 +10 → 次の回は抜けられる（フルパ以上）／指定キャラ使用（フルパ以下）
- 合計 −10 → IGLの権利 1ウェーブ

他の配信者がこの企画をそのまま流用する場合、ルール文言は `control.html`（参加者向けの参考表示）と `display.html`（`EFFECT_TEXT`、達成演出の文言）を書き換えることでカスタマイズできます。仕組み自体（＋1/－1/±10リセット）はコード変更不要です。

## 使い方（配信中）

1. `display.html` をOBSのブラウザソース（ローカルファイルまたは公開URL）として追加し、配信画面の好きな位置に配置
2. スマホなど別デバイスのブラウザで `https://gogomac.netlify.app/control.html` を開く（初回のみ4桁パスコードの入力が必要。一度解除すればその端末では再入力不要）
3. ユーザー名を入力し、＋1／－1ボタンで操作（PCブラウザで開いた場合はキーボードの `+` `-` キーも使える）
4. ユーザー名は、既存なら選択・新規なら自動作成される
5. 各ユーザーのポイントが+10または-10に達すると自動でボーナス/ペナルティ演出が出て0にリセットされる

control.htmlとdisplay.htmlはFirebase Realtime Database経由でインターネット越しにリアルタイム同期するため、**別デバイス・別回線からでも操作できます**。

## セットアップ（配信者向け・初回のみ）

このリポジトリをそのまま使う場合、まだ有効なFirebaseプロジェクトへの接続設定が済んでいません。自分の環境で動かすには:

1. [Firebaseコンソール](https://console.firebase.google.com/) でプロジェクトを新規作成（Google Analyticsは不要）
2. 「Realtime Database」を作成
3. 「Authentication」→「Sign-in method」で**匿名認証を有効化**（これを忘れると同期が一切動きません）
4. 「プロジェクトの設定」→「マイアプリ」からウェブアプリを追加し、表示される`firebaseConfig`の値を`firebase-config.js`に貼り付ける
5. Realtime Databaseの「ルール」タブにセキュリティルールを設定する（内容はリポジトリの内部ドキュメント`CLAUDE.md`を参照）
6. `control.html`冒頭の`CONTROL_PASSCODE`定数を好きな4桁に変更する（初期値のまま公開しないこと）

パスコードはUIレベルの簡易的な入場制限であり、リポジトリがpublicである以上「秘密」ではありません。実質的なアクセス制御はFirebase側の匿名認証必須ルールで行っています。
