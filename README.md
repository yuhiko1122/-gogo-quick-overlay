# ゴーゴークイック 参加型ポイントオーバーレイ

Overwatchの参加型企画用、配信オーバーレイです。ユーザーごとにポイントを加減算し、配信画面にリーダーボードとして表示します。サーバー・DBは不要な静的サイトで、ブラウザのlocalStorageのみで動作します。

## ファイル構成

- `display.html` — 配信画面に映す表示用ページ（OBSのブラウザソースに指定）
- `control.html` — ポイントを操作するページ（配信には映さず、操作専用）

## 使い方（OBS）

1. `display.html` をOBSのブラウザソース（ローカルファイル）として追加し、配信画面の好きな位置に配置
2. `control.html` を**同じシーン**にもう一つのブラウザソースとして追加し、目のアイコンで非表示にする
3. 操作したいときは control.html のソースを右クリック→「操作（Interact）」でポップアップを開き、＋1／－1ボタンかキーボードの `+` `-` キーで操作
4. ユーザー名を入力すると、既存なら選択・新規なら自動作成される
5. 各ユーザーのポイントが+10または-10に達すると自動でボーナス/ペナルティ演出が出て0にリセットされる

同じブラウザ（同じOBS内）で開いている限り、display.htmlとcontrol.htmlはリアルタイムで同期します。
